## Stage breakdown

01. **The least glamorous moment** (5200ms) — A URL, a few query parameters, a Send button.
02. **Eleven milliseconds** (5400ms) — Three dishes, spicy, none over RM20. The system works.
03. **Who did the work?** (5600ms) — A person knew maxPrice, not priceLimit, and the exact path.
04. **The agent is a caller** (5200ms) — It picks the parameters you would have typed, and reads the JSON you would have read.
05. **But the API was missing** (5400ms) — The reference app reads its menu on the client. No server, nothing to call.
06. **Build it, step by step** (5200ms) — Minimal API, EF Core, a migration, seed data, one test per method.
07. **Postman first** (5400ms) — If the URL is wrong, the failure arrives dressed as an AI problem.
08. **Then hand it over** (5800ms) — One function tool, one schema. The agent turns a sentence into the same call.
09. **Build the URL first, then the agent** (4800ms) — A wrong URL fails dressed as an AI problem, the most expensive kind of bug.
