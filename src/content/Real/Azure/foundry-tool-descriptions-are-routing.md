## Stage breakdown

01. **No way to the price** (5200ms) — The agent refused to invent a price, and had no tool to look one up.
02. **Too many tools** (5400ms) — The first version had too many, and the model kept picking the wrong one.
03. **Nine survive** (5600ms) — Nine tools, each a thin wrapper over a tested service method.
04. **When NOT to use it** (5200ms) — The change that fixed most wrong-tool calls: a sentence saying when the tool does not apply.
05. **The run loop** (5400ms) — Response asks for a tool, the executor runs it, outputs go back.
06. **Errors as data** (5200ms) — A tool failure returns a structured error the model can read, not an exception.
07. **Cap the rounds** (5400ms) — Past the cap, stop and tell the user. Never loop forever.
08. **Trim the output** (5800ms) — Return the fields the answer needs, not the whole row.
09. **Descriptions route, caps stop loops** (4800ms) — Errors as data, trimmed output, and a hard limit on tool rounds.
