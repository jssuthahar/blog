# Icon sets used in article diagrams

Two sets, kept separate because their licences and their rules differ.

## `azure/` — Microsoft Azure architecture icons

Source: https://learn.microsoft.com/en-us/azure/architecture/icons/
Set: Azure_Public_Service_Icons_V24

> Microsoft permits the use of these icons in architectural diagrams, training
> materials, or documentation. You can copy, distribute, and display the icons
> only for the permitted use unless granted explicit permission by Microsoft.
> Microsoft reserves all other rights.

Served unmodified: not cropped, flipped, rotated, distorted or recoloured. Each
one is labelled with the Azure product name it represents, and is used only for
that product — never to stand in for something that is not an Azure service.

## `material/` — Google Material Symbols

Source: https://fonts.google.com/icons
Repository: https://github.com/google/material-design-icons
Licence: Apache License 2.0 — http://www.apache.org/licenses/LICENSE-2.0

Copyright Google LLC, licensed under the Apache License, Version 2.0. Used for
everything that is not an Azure service: a phone, a terminal, a key, a clock, a
blocked request. Apache 2.0 permits modification, so these are rendered through
a CSS mask and inherit the page's text colour.
