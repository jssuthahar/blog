1 · The old model

How PRU multipliers worked

Under request-based billing, each prompt you sent in Copilot Chat (ask, edit, agent or plan mode) used one premium request, multiplied by the model’s multiplier. A cheap model might count as 0.33 of a request; a frontier model as 27. The prompt’s length didn’t matter. Agent tool calls didn’t count, only your prompts. Copilot code review used 13 per review.

2 · The change

Why GitHub moved to AI Credits

Copilot now runs long, multi-step agent sessions across whole repositories. Under PRU billing, a quick question and a multi-hour agent session could cost the same, while the real compute differed by thousands of times. GitHub said that model was no longer sustainable, and moved to billing by actual tokens at each model’s published rates.

3 · The units

Input, output and cached tokens

InputEverything sent: your prompt, instructions, tool definitions, history, files, tool results.Full input price
OutputEverything the model writes, including hidden reasoning, which OpenAI and Anthropic bill as output.3–8× input
Cached inputA repeated prefix reused from a recent request.Usually 10% of input or less; 25% on Grok
Cache writeStoring a prefix for reuse. Charged on Anthropic models and the GPT‑5.6, GPT‑6 and GPT‑6.1 families.About 1.25× input
credits = (fresh input × input rate + cached × cached rate + cache writes × write rate + output × output rate) ÷ 1,000,000 × 100

6 · Agents

Why agent mode can become expensive

Under PRU billing, one prompt to an agent was one request, no matter how many steps it took. Under AI Credits, every model call in the loop is billed, and each call re-sends the growing conversation plus the latest tool output.

9 · Budget

Tips to save your monthly AI Credits budget

Use the free partCode completions and next edit suggestions don’t use AI Credits. Let them do boilerplate.
Default to AutoOn paid plans, Auto model selection in Copilot Chat and the cloud agent takes 10% off model costs.
Check weeklyThe AI usage page shows credits by feature and model. Catch a runaway agent early.
Cap sessionsSet an AI credit session limit in Copilot CLI so long agent tasks stop and ask.
Mind code reviewEach Copilot review uses AI Credits plus GitHub Actions minutes. Request it where it adds value.
Plan budgets with adminsUser-level budgets cap one person; additional usage is on by default for organizations.
Front-load the monthCredits reset on the 1st (00:00 UTC) and don’t roll over; pace big agent jobs across the month.
Share what worksCommit good prompt files, skills and lean instructions so everyone benefits.
Keep tools updatedOlder IDE and CLI versions can show wrong usage. Update VS Code, JetBrains and Copilot CLI.
