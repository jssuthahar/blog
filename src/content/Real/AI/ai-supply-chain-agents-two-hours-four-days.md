## Stage breakdown

01. **One line, two hours saved** (5200ms) — A package solves an immediate problem. Nobody reviews a pubspec line.
02. **It spreads** (5400ms) — Already there, so it gets imported in three features.
03. **A denied licence** (5600ms) — Eleven days before launch, the licence turns out to be one the store build cannot ship.
04. **Count the imports** (5200ms) — For each declared package: how many files in lib/ import it?
05. **uuid: zero files** (5400ms) — docs/dependencies.md still has a reason for it. The code moved on.
06. **A reason per package** (5200ms) — pre-commit: a new package needs a row in docs/dependencies.md.
07. **Deny list on the whole tree** (5400ms) — pre-push: denied licences in the resolved tree. Transitive counts.
08. **Caught on the day** (5800ms) — The same package now fails the push the day it is added, while it is in one file.
09. **Two hours on day one** (4800ms) — A reason per package, a deny list on the tree, a source per asset, an inventory for privacy.
