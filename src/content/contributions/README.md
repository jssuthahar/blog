Every other file in this folder is one public community contribution. Copy the
frontmatter below, fill it in, and it appears on `/contributions` automatically —
grouped by year, counted by type, and filterable by ecosystem.

Delete this file once you have real entries; it only exists as a template.

```yaml
---
title: 'Building RAG Applications with Azure OpenAI'
kind: talk            # talk | video | article | oss | course | community | book
date: 2026-05-14
venue: 'Global Azure Bootcamp'
location: 'Kuala Lumpur, Malaysia'
url: 'https://example.com/session'
ecosystem: microsoft  # microsoft | google | other
technologies: ['Azure OpenAI', 'C#', 'RAG']
reach: '250 attendees'
featured: true
---
```

## Why this page exists

MVP and GDE nominations are judged on a dated, verifiable record of public
contribution — weighted heavily toward the **last 12 months**. Reviewers want
links, dates, and reach, not adjectives.

Keeping the record as structured data means that at nomination time it is
already sorted, counted, and exportable, instead of something you reconstruct
from memory across YouTube, LinkedIn, and email.

Log contributions as they happen. The reconstruction is the part that
otherwise never gets done.
