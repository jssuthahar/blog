🔔 Event Grid
🔔 rings, then done
1a thing that happened 2it pushes to your handler 3delivered, then gone 4it retries, then dead-letters 5discrete reactions
📼 Event Hubs
kept, and rewindable
1a series of things 2you read a log 3kept for the retention window 4you re-read from a checkpoint 5millions per second
💡 One tells you something happened. The other keeps a record of everything that did.
