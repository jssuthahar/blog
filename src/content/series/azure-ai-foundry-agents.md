Most agent tutorials start with an empty folder. Real work starts with an app that already has customers, roles, an API and a database. This series takes one running food delivery platform and adds AI agents to it, in order: what Foundry actually is and when you need it, the business case, the project setup, the function tools that wrap existing business APIs, the JWT and role model that decides what an agent may touch, the mobile client, everything that goes wrong once the traffic is real, and finally MCP and multi-agent handoff for when one agent is no longer enough.
