Q0 Which queue should you actually use? let's find out
📮 Queue Storage
in the running
❌no topics at all ⚠️best-effort order ⚠️64 KB ceiling ⚠️you check DequeueCount ✅the whole storage account
📥 Service Bus
in the running
✅topics + subscriptions ✅FIFO with sessions ✅256 KB · 100 MB premium ✅DLQ, dedupe, transactions ⚠️80 GB and that is it
💡 Both are queues. Only one of them is the cheap one already in your resource group.
START You will make this call this week. Make it on a question, not a habit.
more than one consumer? Service Bus
does order matter? Service Bus
message over 64 KB? Service Bus
need DLQ, dedupe, transactions? Service Bus
more than 80 GB queued? Queue Storage
any yes → Service Bus all no → Queue Storage
