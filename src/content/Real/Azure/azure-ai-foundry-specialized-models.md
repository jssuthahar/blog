## Stage breakdown

01. **Can one model handle six different jobs?** (2600ms) — No. Search, images, video, claims and calls each need a different kind of model.
02. **What does Azure AI Foundry actually offer?** (2800ms) — Embeddings, image and video generation, vision, speech to text and text to speech — one catalog.
03. **How do you search when the words don't match?** (2900ms) — Ada and Cohere embeddings match by meaning, so "wet shoes" still finds the refund policy.
04. **Need 30 product shots by tomorrow?** (2600ms) — GPT-image-1 renders the full set from one prompt — no design queue required.
05. **Can you test an ad before the shoot?** (2600ms) — Sora 2 renders a 15-second teaser from one text prompt — no crew, no location, no wait.
06. **One damage photo. What happens next?** (2900ms) — GPT-4.1 reads the photo and drafts damage, severity and cost before anyone opens the ticket.
07. **How do you handle support calls at scale?** (2900ms) — GPT-4o-transcribe writes the call down; GPT-4o-tts speaks the confirmation back.
08. **So who's actually using this?** (2700ms) — Search, marketing, claims and support — one Foundry catalog behind all four.
